# Контекст проекта

Мобильная страница-инструкция по заправкам для водителей (SIA HEAD, HDLG). Один экран: дата действия, баннер про изменения, раскрывающиеся карточки-блоки.

Боевой адрес: https://siahead2017-png.github.io/FuelInstruction/

**Язык общения с пользователем — русский.** Интерфейс тоже только русский. Владелец не программист — объяснять просто, без жаргона.

Родственный проект — [Driver_Instructions](../Driver_Instructions/CLAUDE.md) (тот же владелец, тот же GitHub-аккаунт `siahead2017-png`, но **отдельный репозиторий** и отдельный GitHub Pages сайт). Не путать домены при правках — оба называются похоже по-русски, но это разные `github.io/...` пути.

## Главное правило

**Никакой сборки и никаких зависимостей.** Всё в одном `index.html`: разметка, `<style>`, `<script>` — без React/Vite/бандлеров. GitHub Pages отдаёт файл как есть.

## Данные — не редактируются в коде

Контент (дата, доп. правила, цены на DIESEL, список блоков-инструкций) **не хранится в репозитории**. Он подтягивается на клиенте из Google Таблицы, опубликованной как CSV (`Файл → Опубликовать в интернете`), двумя запросами (см. `index.html`):

- `META_CSV_URL` — лист с метаданными: `[0]` дата действия, `[1]` доп. правила, `[2]` цены на DIESEL;
- `BLOCKS_CSV_URL` — лист с блоками инструкций, колонки: заголовок, подзаголовок, основная, резервная, доп. правила.

Значит: чтобы поменять **текст инструкции**, репозиторий трогать не нужно — правки идут в Google Таблице у владельца. Правки в этом репо нужны только для внешнего вида, иконки, структуры страницы.

`fetch(..., {cache:'no-store'})` — данные не кешируются намеренно, чтобы владелец сразу видел свои правки в таблице.

| `index.html` | Всё: разметка, стили, JS-логика загрузки CSV и рендера аккордеона |

## Иконка и установка на телефон (июль 2026)

Изначально в проекте не было ни `manifest.webmanifest`, ни `apple-touch-icon` — при установке на главный экран Android/iOS подставляли системную иконку по умолчанию вместо лого. Добавлены оба.

**Кеш: версионные метки `?v=N` — обязательно**, иначе браузер/установленное приложение продолжат показывать старую иконку. При замене любого `icon-*.png` или `favicon.png` поднимай `?v=` сразу в двух местах:

- `index.html` → `<link rel="icon">` и `<link rel="apple-touch-icon">`
- `manifest.webmanifest` → все 4 `src` в `icons`

Сейчас версия `?v=1`.

**Название на главном экране** — два разных поля с разным назначением:
- `name` (манифест) — полное название, показывается в системных диалогах установки/обновления. Сейчас: «DIESEL Инструкция (HEAD, HDLG)».
- `short_name` (манифест) + `apple-mobile-web-app-title` (index.html, для iOS) — короткая подпись **под иконкой** на экране. Длинный текст телефон обрежет (~10-12 символов помещается). Сейчас: «HEAD,HDLG Заправки».

Если владелец меняет название ещё раз — трогать нужно оба поля синхронно (name — для смысла, short_name/apple-mobile-web-app-title — для подписи под иконкой).

При смене имени/иконки уже установленного приложения Chrome/Android покажет диалог-подтверждение «Проверьте новое название» — это штатное поведение (защита от подмены манифеста), нужно нажать «ОК». Сам ярлык на экране не обновляется, пока владелец не подтвердит или не переустановит его.
